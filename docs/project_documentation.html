Labour Sampark App

Project Documentation

Labour Sampark is a Flutter mobile app that connects labourers, contractors, and subcontractors with fast login, verification, notifications, and dashboard workflows.

Business Purpose

This project is built to simplify hiring and job coordination between labourers and contractors. It provides a digital platform for:

  • Quick worker discovery and contractor contact.
  • OTP-based secure verification for trusted access.
  • Real-time communication and notifications via Firebase Messaging.
  • Improved operational efficiency for labour-based businesses.

Target Audience

Business Stakeholders

  • Contractors and companies that need reliable labour resources.
  • Labourers seeking work opportunities and quick onboarding.
  • Operations teams needing notifications and session-based access.

Technical Team

  • Built with Flutter for cross-platform mobile deployment.
  • Firebase backend support for messaging, crash reporting, and analytics.
  • Persistent local session storage with SharedPreferences.
  • Modern state handling via Provider and GetX.

Technical Overview

The codebase is organized with a standard Flutter app structure and uses Firebase for remote features. Key responsibilities are:

  • Startup: `lib/main.dart` handles Firebase initialization, notification setup, and app lifecycle checking.
  • Authentication: `lib/core/auth_service.dart` manages login state, tokens, and OTP verification flags.
  • Screens: `SplashScreen`, `LoginScreen`, `MobileVerifyScreen`, and `UserDashboardScreen` define the main app flow.
  • Notifications: Real-time Firebase Cloud Messaging in both foreground and background.
  • Local storage: Uses `SharedPreferences` and `hive` for session and preferences data.

Core Features

  • Branding and native splash using `flutter_native_splash`.
  • OTP verification flow for mobile users.
  • Crash reporting through `firebase_crashlytics`.
  • Push notifications and deep linking via `firebase_messaging`.
  • In-app update support for Android using `in_app_update`.
  • Responsive UI scaling with `flutter_screenutil`.
  • Location services via `geolocator` and `geocoding` for future location-aware functionality.

Project Status

  • App is currently at version 1.0.9+14.
  • Most startup, login, OTP, and dashboard navigation are implemented.
  • Core backend connectivity is present via `ApiService` and Firebase integrations.
  • Further work may include expanded dashboard features, role-based screens, and improved business analytics.

How to Build

  • Install Flutter SDK and configure Android/iOS tooling.
  • Run flutter pub get in the project root.
  • Use flutter run to launch on a device or emulator.
  • Use flutter build appbundle --release for Android production build.
  • Ensure Firebase configuration files exist for Android and iOS.
